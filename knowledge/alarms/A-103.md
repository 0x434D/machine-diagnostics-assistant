# A-103 · Component code not read

**Station** S1 Feeding · **Severity** warning · the lane code reader could not read a
component serial.

## What it means

A component was present but its identity was not captured. The consequence is in the
traceability data, not in the production: **that assembly's genealogy is incomplete.**

## Why this alarm matters more than its severity suggests

A no-read and a missing component look similar in the record and mean opposite things:

| | Component absent | Code not read |
|---|---|---|
| Physical part | not there | there |
| Assembly | defective, `missing_part` | fine |
| Containment | not affected | **cannot be excluded** |

The second row is the trap. An assembly with an unread component cannot be proven to be
outside a lot containment, because nobody knows which lot it came from. It has to be listed
as unknown rather than quietly dropped from the scope.

## Check

1. Whether the assembly was created and completed normally.
2. Whether the no-reads cluster — one lane, one period, one lot boundary.
3. Any containment scoped over this window: report the unknowns as a separate count.

## What it does not mean

It does not mean a part is missing. Do not route this to `missing_part` without checking
whether the component is physically there.

See also: S1, `missing_part`, SOP-04.
