R4 image-size measurement (Task 5, Step 10 -- re-measured after review round 1, R-H7)

Round-1 defect: this file's first version rendered 500 x ["gap"] at the pre-R-H7
resolution and PNG settings; "gap" (and "missing_part") drew a fixed rectangle
independent of part_id, so all 500 renders were byte-identical -- one image measured
500 times, not a distribution.

R-H7 changes applied before this remeasurement:
  - Default resolution 640x480 -> 320x240 (simulator.config.Settings.image_width/height).
  - PNG compress_level=1 (new Settings.image_compress_level), not optimize=True.
  - Deterministic seeded sensor noise added to the render (simulator.render.render_part /
    inspection.render.render_part), keyed `f"{seed}:{part_id}:noise"` -- a separate RNG
    stream from the one that positions defects, so noise and defect geometry never share
    a knob.
  - `gap` now positions its bar at the RNG's x (was fixed at the seam's midpoint);
    `missing_part` now covers a band around the RNG's y (was the whole second
    component, always). Both were degenerate by construction before this; noise alone
    would have masked that without removing it.

Command (mirrors InspectionClient.produce's own defect-selection key exactly, so this
measures what actually gets rendered for a reject in production):

cd plant && uv run --frozen --package simulator python - <<'EOF'
import random
from simulator.config import Settings
from simulator.inspection_client import DEFECT_CLASSES
from simulator.render import render_part

settings = Settings()
sizes = []
for i in range(500):
    part_id = f"A-{i:08d}"
    rng = random.Random(f"{settings.seed}:{part_id}:defect")
    defect = rng.choice(DEFECT_CLASSES)
    sizes.append(len(render_part(
        part_id, [defect], settings.image_width, settings.image_height,
        settings.seed, settings.image_compress_level,
    )))
sizes.sort()
p50 = sizes[len(sizes) // 2]
p99 = sizes[int(len(sizes) * 0.99)]
mx = sizes[-1]
print(f"img_p50={p50} img_p99={p99} max={mx} distinct={len(set(sizes))} n={len(sizes)}")
EOF

  - MaxByteStringLength = 4,194,304 B (4 MiB): NOT crossed. img_p99 (110,419 B) is
    ~38x below this ceiling, so at this configuration the ceiling search a later task
    runs against img_p99 starts from real headroom, not from a value already near it.

Byte-identity check (§3.6), both previously-degenerate classes, spot-checked directly
against simulator.render.render_part:
  - render_part("A-00000001", ["gap"], 320, 240, seed=20260912, compress_level=1)

  - Same call for part_id "A-00000002": differs from "A-00000001"'s (109780 bytes).
